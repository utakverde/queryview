ECPay · Import Paid Bills

Post verified payments

Accepted formats: TXT, CSV, XLS, XLSX. Select multiple daily files to combine them into one posting batch. Choose Use one date for all and enter a custom ORCollection to post every imported row with the same date and OR. Leave ORCollection as Automatic ECPAY-mddyy to generate it from each posting date. Posting matches the exact account number and total unpaid amount including all arrears; the imported name is for display only. A payment can cover any number of unpaid bills when their combined balance matches exactly and the selected current bill month is present. Previously paid rows are safely skipped so the remaining rows can be reposted. Posting sets flag_paid='Y', date_paid, resolves collector_code from the office's exact ECPay user, and writes the displayed OR value. Invalid OR values, missing accounts, and amount mismatches are blocked.
