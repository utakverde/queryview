ECPay · Import Paid Bills

Post verified payments

Bill months included

Accepted formats: TXT, CSV, XLS, XLSX. Select multiple daily files to combine them into one posting batch. Choose Use one date for all and enter a custom ORCollection to post every imported row with the same date and OR. Leave ORCollection as Automatic ECPAY-mddyy to generate it from each posting date. Posting checks the selected bill months from newest to oldest. For each month, it compares the payment with the unpaid total through that month, including earlier arrears. When a total matches, only bills through the matched month are marked paid; newer unpaid bills remain unpaid. If none match exactly, posting is blocked. The imported name is for display only. For mixed billing cycles, select every Bill Month represented in the import and confirm the month on each preview row. If the payment file has a BillMonth, preview uses it when that bill is still unpaid. If the file has no BillMonth, preview chooses the newest selected month that has an unpaid bill for each account; if the newest reading is not posted yet, it falls back to an older selected unpaid month. You can change a row manually, and posting rechecks the unpaid balance and month. Previously paid rows with a matching account, bill month, amount, and source payment date are safely skipped and retained in transaction history with the source reference and existing paid date/OR for refund review. Posting sets flag_paid='Y', date_paid, resolves collector_code from the office's exact ECPay user, and writes the displayed OR value. Invalid OR values, missing accounts, and amount mismatches are blocked.

ECPay · Status monitoring

Transaction status

Each posting transaction is summarized as Success, Partial, Failed, Skipped, or Resolved. Resolved rows are already paid in billing with the matching ECPay date and OR. Open the current bill month error count to review the affected payment rows. Transaction exports include Failed, Skipped, Manual Review, Posted Later, Failure Types, and Bill Month Errors sheets. Manual Review excludes failed rows matched to a later successful posting; check skipped-row reasons before manual posting.
